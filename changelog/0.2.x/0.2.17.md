# 0.2.17 — 2026-08-22

## Changed

- **MCP protocol compatibility** now includes revision `2026-07-28` alongside 2025-era clients; undeclared tool arguments are rejected by name instead of being silently discarded.
- **HTTP session mode** is explicitly stateless across the environment example, Docker image, plugin manifests, MCPB configuration, MCP Registry metadata, and README.
- **Build and packaging tooling** now follows the current scaffold: TypeScript 7 typechecks source and tests, Docker builds both architectures with Bun 1.4 while omitting optional peers, and `.mcpb` cleanup strips platform-specific native bindings.
- **Community metadata** adds contributor and conduct guidance, and directs vulnerability reports to `security@caseyjhand.com`.

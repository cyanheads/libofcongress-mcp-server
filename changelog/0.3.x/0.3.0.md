# 0.3.0 — 2026-09-22

## Changed

- **`search_newspapers` and `get_newspaper_page` return `states: string[]`** in place of `state` — a newspaper title indexed against its circulation area lists more than one state ([#43](https://github.com/cyanheads/libofcongress-mcp-server/issues/43)).
- **`search_subjects` drops `count`** — the upstream field tallies matching authority records, not LOC items, so it carried no research signal; get a heading's real item count from `search`'s `total` with the heading as the `subject` filter ([#41](https://github.com/cyanheads/libofcongress-mcp-server/issues/41)).

## Fixed

- **Out-of-range search pages** — a page past the end of a search-family endpoint's results (404 on `page > 1`) now returns an empty result with a notice pointing back to page 1, instead of surfacing as an error ([#40](https://github.com/cyanheads/libofcongress-mcp-server/issues/40)).
- **Recovery hints reach the wire** — every `ctx.fail` site now forwards its contract's `recovery` hint; `rate_limit_exceeded` carries the exact minutes left and the block's expiry time instead of the contract's static "about an hour" ([#44](https://github.com/cyanheads/libofcongress-mcp-server/issues/44)).
- **Declared validation reasons** — `invalid_date_range` and `invalid_page_url` replace bare validation throws, so callers can switch on `data.reason` ([#45](https://github.com/cyanheads/libofcongress-mcp-server/issues/45)).
- **`related_items` entries normalized to strings** — an object entry (`{ title, url }`) now normalizes to `id`, then `url`, then `title`, instead of failing output validation ([#39](https://github.com/cyanheads/libofcongress-mcp-server/issues/39)).
- **`contributors` reads `contributor_names`** — includes each person's role (e.g. "Washington, George, 1732-1799 (Author)"); the prior field read a key carrying the same people without roles ([#47](https://github.com/cyanheads/libofcongress-mcp-server/issues/47)).
- **`get_newspaper_page` returns publication metadata** — `newspaper_title`, `place_of_publication`, `states`, `edition`, `date`, and the issue's `segment_count` now come from the same request as the OCR text ([#42](https://github.com/cyanheads/libofcongress-mcp-server/issues/42)).

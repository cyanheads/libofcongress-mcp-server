# 0.6.0 — 2026-11-03

## Added

- Publish the libofcongress-guide research skill through MCP skill resources and package installs.
- **`libofcongress_search_subjects`** accepts zero-based `offset` and returns `next_offset`, with up to 250 headings per call and consistent exact-label promotion across pages and changed limits. ([#80](https://github.com/cyanheads/libofcongress-mcp-server/issues/80))
- **Search ordering** accepts `sort: relevance | date | date_desc` on item and newspaper searches, with `effectiveSort` on both output surfaces. ([#81](https://github.com/cyanheads/libofcongress-mcp-server/issues/81))
- **Newspaper-page search rows** expose `page_url` for `libofcongress_get_newspaper_page`, retaining the original URL and non-item identity. ([#84](https://github.com/cyanheads/libofcongress-mcp-server/issues/84))
- **Agent Plugins manifests** add root `plugin.json` and `mcp.json` for compatible plugin clients.

## Changed

- **Collection browsing** combines `collection_slug` with all eight material formats through LOC's `original-format` facet; tool descriptions and server instructions document match-all `query: "*"` and the collection-to-search chain. ([#83](https://github.com/cyanheads/libofcongress-mcp-server/issues/83))
- **Development tooling** syncs framework skills, packaging and audit checks; MCPB cleanup removes build-only files while retaining SDK skill runtime modules. npm and Docker include the research guide, and README setup instructions lead with hosted and local client commands.
- **Install policy** sets `minimumReleaseAge` to one day; package manager and Docker stages use Bun 1.4.4.

## Removed

- **Failed OCR match results** omit `matches` and `match_count` when text retrieval is unavailable or unparseable. Treat absent fields as unknown; image-only, blank, and successfully scanned no-hit pages retain empty matches and zero counts. ([#79](https://github.com/cyanheads/libofcongress-mcp-server/issues/79))

## Fixed

- **Retired catalog links** retain their original URL and carry `link_notice` on both output surfaces instead of advice to open a working record. ([#76](https://github.com/cyanheads/libofcongress-mcp-server/issues/76))
- **Markdown rendering** preserves catalog punctuation and notices as literal text, with framework error and enrichment rendering covered by parsed-output assertions.
- **Newspaper geography descriptions** identify LOC's indexed State/Province values separately from place of publication.

# 0.5.1 — 2026-10-15

## Added

- **`libofcongress_get_newspaper_page` `match`** ([#73](https://github.com/cyanheads/libofcongress-mcp-server/issues/73)): returns `matches` (up to 10 passages, about 300 characters either side of each occurrence) and `match_count` instead of the whole page; `ocr_text` is empty. Words are separate terms, a double-quoted span is one phrase, matching is case-insensitive and literal. Pass the search query; the server instructions now say so.
- **`libofcongress_get_newspaper_page` `item_id`** ([#72](https://github.com/cyanheads/libofcongress-mcp-server/issues/72)): the item the page belongs to (newspaper issue, book, or manuscript volume), for `libofcongress_get_item` to list every page.
- **`libofcongress_get_newspaper_page` `item_title`** ([#74](https://github.com/cyanheads/libofcongress-mcp-server/issues/74)): the title of the item the page belongs to, on every page type; it heads book and manuscript pages in the text output.
- **`libofcongress_get_item` `imprint`** ([#71](https://github.com/cyanheads/libofcongress-mcp-server/issues/71)): place, publisher, and date as cataloged (`New York : Werner School Book Company, c1900.`), also on the item resource.

## Changed

- **`libofcongress_get_item` and the item resource accept `lccn.loc.gov` links** ([#68](https://github.com/cyanheads/libofcongress-mcp-server/issues/68)) (`https://lccn.loc.gov/2005567251`) as the item ID, with the LCCN normalized (`2005-568294` as `2005568294`). Other `lccn.loc.gov` paths stay `invalid_item_id`.
- **`libofcongress_search_items` `is_item` is `true` for `lccn.loc.gov` rows** ([#68](https://github.com/cyanheads/libofcongress-mcp-server/issues/68)), whose `id` is the bare LCCN. `catalog.loc.gov` records and `hdl.loc.gov` finding aids stay `false`.
- **`libofcongress_search_newspapers` calls its excerpt the page's opening text** ([#73](https://github.com/cyanheads/libofcongress-mcp-server/issues/73)) and points to `match` for the passages around a hit.
- **`CLAUDE.md` / `AGENTS.md`**: releases go through a gated release PR, reviewed before publish; the structure map lists `page-text-match.ts`, and the Zod version reads ^4.6.7.

## Fixed

- **A coded catalog value is no longer returned as `date`** ([#69](https://github.com/cyanheads/libofcongress-mcp-server/issues/69)) (`uuuu`, `185u`, `18950000`, `0w0 d1804 d1806`). A search row falls back to its top-level `date`, then to none; `libofcongress_get_item` omits `date`.
- **LOC's blank-page placeholder `[NO TEXT AVAILABLE FOR THIS PAGE]` is returned as empty `ocr_text`** ([#70](https://github.com/cyanheads/libofcongress-mcp-server/issues/70)), with the empty-text notice.
- **Image-only pages with an empty `fulltext_service` report `ocr_available: false`** ([#75](https://github.com/cyanheads/libofcongress-mcp-server/issues/75)) and no retry notice.
